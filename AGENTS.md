# Правила работы с проектом

## Основной файл

— Основной файл сайта: `index.html`
— Сайт одностраничный
— Не разделять файл на CSS/JS/HTML без отдельной команды

## Главное правило

— Не менять блоки сайта, если задача не просит
— Не переписывать весь сайт без прямого запроса
— Все правки делать точечно
— Сохранять текущую структуру и визуальный стиль

## Что нельзя удалять

— Телефонию
— Скрытые номера для телефонии
— Формы заявок
— Модальные окна заявок
— Cookie-уведомление
— Политику обработки персональных данных
— Согласие на обработку персональных данных
— Галочки согласия в формах

## После каждой правки проверить

— Открываются ли кнопки заявок
— Работают ли модальные окна
— Не сломался ли хедер
— Не пропали ли телефоны
— Не пропали ли блоки согласий
— Нет ли ошибок в консоли

## Стиль правок

— Не добавлять лишние тексты от себя
— Не менять офферы без задачи
— Не менять логотип без задачи
— Не менять изображения банков без задачи
— Не менять структуру проектов домов без задачи
